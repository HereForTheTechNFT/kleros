# 4. Mecanismes de valeur

Le coeur economique du protocole est porte par Court tree, PNK staking, juror selection, disputes, evidence, appeal rounds. Ces mecanismes determinent qui fournit la liquidite, qui assume le risque et comment les pertes ou revenus sont distribues. Les appels externes, les callbacks et les mises a jour d index sont des frontieres importantes pour une revue de securite.
